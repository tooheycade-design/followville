# Followville interior asset catalog

The runtime catalog in `quaternius/` contains a curated subset of the
**Ultimate House Interior Pack** by Quaternius. The source pack and every model
used here are released under CC0 1.0 for personal and commercial use.

- Official source: https://quaternius.com/packs/ultimatehomeinterior.html
- Download mirror used for the web-ready GLB files and preview images:
  https://poly.pizza/bundle/Ultimate-House-Interior-Pack-2SXnFbwFzm
- License: https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-08-03

Followville keeps the files local rather than loading third-party URLs at
runtime. This avoids availability, privacy and performance surprises. The
human-readable catalog, approved dimensions and collision footprints live in
`interior-system.js`; unlisted files cannot be requested through saved house
customization data.
